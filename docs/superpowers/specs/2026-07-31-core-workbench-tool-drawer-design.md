# 核心工作台与工具抽屉设计规格

## 目标

把 Morpheus Video Studio 的首页收敛成清晰、简洁的创作工作台。高频创作能力直接展示在主画面，低频管理能力统一放入默认收起的左侧边栏，避免重复入口和信息噪音。

## 信息架构

### 主画面：核心工作台

主画面只突出四个核心模块：

1. 内容创作：进入 Content Library，导入或整理文案、PDF、书摘和脚本。
2. 音频创作：进入 Audio Workshop，生成旁白和声音资产。
3. 视频创作：进入 Video Workshop，生成或继续制作视频。
4. 数字人口播：进入 Digital Human，制作数字人口播内容。

Studio 首页不再重复展示 Settings、资产库、History 等管理入口，也不展示大段产品说明。首页由以下内容组成：

- 简短的工作台标题和一句说明。
- 四个核心模块入口。
- 一个“继续创作”区域：有最近工作时显示最近项目；没有数据时提供简短的新建引导。

### 左侧可隐藏边栏：工具抽屉

左侧边栏默认收起，只承载低频管理入口：

1. 已有资产：进入 Asset Library。
2. 视频项目：进入 History，查看已经生成和正在继续制作的视频项目。
3. 系统设置：进入 Settings。

边栏入口使用中文名称，保持短而明确。主画面不再重复放置这些入口。

## 导航行为

- 应用首次打开时，左侧边栏保持收起。
- 用户展开边栏后，可以访问“已有资产”“视频项目”“系统设置”。
- 四个核心模块从 Studio 首页直接进入，不依赖展开边栏。
- 当前的业务页面和后端能力保持不变，本次只调整入口层级、首页内容和视觉表达。
- 不删除任何页面，不改变已有生成流程、配置格式或数据目录。

## 视觉设计

整体采用简洁的专业浅色工作台：

- 背景保持中性浅灰或白色，深海军蓝作为唯一主强调色。
- 首页内容左对齐，限制最大内容宽度，增加稳定留白。
- 减少阴影、渐变、装饰性标签和重复卡片。
- 四个核心模块使用清晰的两列布局；窄屏自动变为单列。
- 模块入口包含名称、一句用途说明和明确的进入动作。
- 指标只在对用户决策有帮助时显示；不再为了填满首页展示多个零值统计框。
- 动效仅保留轻微的悬停和按下反馈，不使用持续动画。
- 沿用项目现有字体与 Streamlit 组件，不引入新的前端框架或第三方依赖。

## 空状态与最近工作

- 没有历史项目时，“继续创作”显示一句空状态说明和“开始视频创作”入口。
- 有历史项目时，仅显示最近一个可继续项目的标题、时间、状态和继续按钮。
- 首页不展开完整历史列表；完整列表留在左侧边栏的“视频项目”页面。
- 资产为空时不在首页显示零值资产面板。

## 视频创作栏目

视频创作的“内容栏目”统一为八个广泛、容易理解的题材入口：

1. 自由创作
2. 知识科普
3. 故事讲述
4. 历史人文
5. 实用教程
6. 观点评论
7. 盘点推荐
8. 健康生活

栏目名称不再混用“表达结构”和“细分行业”。原来的中药与医学一级栏目并入“健康生活”，健康类内容继续保留不夸大疗效、不替代诊疗、必要时提醒就医等安全规则。

每个栏目提供对应的文案结构提示，但不限制用户输入的具体主题。未知或未选择的栏目继续按“自由创作”处理。

## 文案长度与分镜规则

- 主题创作模式无法从短主题本身推断目标视频长度，因此必须尊重用户选择的目标分镜数。
- “按文案长度自动估算分镜数”只对上传文档或已经存在完整文案的模式生效。
- 生成主题草稿时，不得因为主题文字很短而把 5 个目标分镜静默压缩成 1 个。
- 草稿生成后，页面可以基于完整草稿显示预计旁白时长和建议分镜数，但不得自动覆盖用户已经选择的目标分镜数。
- 如果 LLM 返回的段落数少于目标分镜数，沿用现有校验并显示明确错误，不接受不完整草稿。

## 实现边界

预计修改：

- `web/app.py`：把主导航分为隐藏工具页，并保证左侧栏默认收起。
- `web/pages/1_🏠_Studio.py`：收敛首页内容与核心入口。
- `web/components/studio_shell.py`：补充简洁工作台所需的样式或小型复用组件。
- `web/components/content_input.py`：修正主题模式的分镜估算逻辑和栏目说明。
- `morpheus_video_studio/prompts/content_recipes.py`：提供八类通用栏目配方。
- `tests/`：增加导航分组和首页核心入口的回归测试。

不在本次范围：

- 重构视频、TTS、ComfyUI 或 LLM 服务。
- 修改 Asset Library、History、Settings 的业务功能。
- 合并或删除已有数据。
- 调整 GitHub 默认分支或发布版本号。

## 验收标准

1. 初次打开 Studio 时左侧边栏默认收起。
2. 首页只突出内容、音频、视频、数字人四个核心模块。
3. 已有资产、视频项目、系统设置只出现在可隐藏左侧边栏，不在首页重复出现。
4. 四个核心入口均可打开对应现有页面。
5. 首页在桌面宽度下结构清楚，在窄屏下没有横向溢出。
6. 空数据状态简洁，不出现大面积零值指标或重复提示。
7. 原有自动化测试通过，新增导航和首页结构测试通过。
8. Streamlit 实际启动后没有页面异常或浏览器控制台错误。
9. 视频创作栏目显示八类通用题材，旧的中药与医学一级栏目不再出现。
10. 输入短主题并选择 5 个分镜时，生成草稿仍向 LLM 请求 5 段，不再自动降为 1 段。
