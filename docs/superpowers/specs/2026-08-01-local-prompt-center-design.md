# Morpheus 本地提示词中心设计

日期：2026-08-01
状态：用户已确认总体方案，待实施

## 目标

把视频创作所需的高质量提示词完整集成进 Morpheus，使日常生成不依赖 GitHub 或任何外部提示词服务。普通用户只选择内容栏目和模板；模板编辑、启停、恢复默认值等低频操作放入左侧可隐藏工具栏。

第一版以稳定、清楚和可维护为优先，不追求导入数量。成功标准是：八个现有内容栏目都有适用模板；生成器能按栏目、分镜数和镜头时长组合提示词；明显过短或结构不完整的草稿不会直接交付。

## 方案比较

### 方案 A：每次从 GitHub 在线读取

优点是上游更新能立即获取。缺点是生成依赖网络、上游目录和文件格式，无法保证稳定性，也可能将低质量或无关提示词直接带进产品。不采用。

### 方案 B：完整复制外部提示词项目

优点是初始内容量大。缺点是绝大多数内容不是视频提示词，许可证和产品结构混杂，升级时容易污染 Morpheus 代码。不采用。

### 方案 C：本地精选模板库

将适合 Morpheus 的提示词重新整理成统一结构，随软件发布并接受本地管理。GitHub 项目只作为人工研究来源，不参与运行时生成。这是采用的方案。

## 用户体验

### 视频工坊

“快速创作”的核心流程保持简洁：

1. 选择内容栏目。
2. 选择该栏目下的提示词模板。默认自动选择推荐模板。
3. 输入主题、标题和分镜数。
4. 生成可编辑文案草稿。

模板选择只显示易懂名称和一句用途说明，不在主页面展示长提示词全文。用户没有主动选择时，系统使用该栏目的推荐模板。

### 左侧工具抽屉

在“已有资产、视频项目、系统设置”同级增加“提示词中心”。该页面提供：

- 按用途和栏目查看模板；
- 查看模板名称、说明、状态和来源；
- 启用或停用模板；
- 编辑用户可调整的模板正文；
- 将单个模板恢复为软件默认版本；
- 预览模板需要的变量；
- 标识当前推荐模板。

提示词中心属于低频管理工具，不进入主工作台核心模块。

## 模板范围

第一版包含四类模板：

1. 主题转文案；
2. 文档转文案；
3. 文案转画面提示词；
4. 文案转视频提示词。

“主题转文案”覆盖现有八个栏目：

- 自由创作；
- 知识科普；
- 故事讲述；
- 历史人文；
- 实用教程；
- 观点评论；
- 盘点推荐；
- 健康生活。

每个栏目至少有一套默认模板。只有确实存在不同创作目的时才增加变体，第一版不为了数量堆积模板。

## 模板结构

每个模板包含以下字段：

- `id`：稳定且唯一的内部标识；
- `name`：用户可理解的名称；
- `purpose`：主题文案、文档文案、画面或视频；
- `category`：适用栏目；
- `description`：一句用途说明；
- `template`：带变量的提示词正文；
- `variables`：允许使用的变量清单；
- `enabled`：是否可用；
- `recommended`：是否为栏目默认模板；
- `source`：`morpheus`、`fabric-inspired` 或其他经审核来源；
- `license_note`：来源与许可证说明；
- `version`：模板版本号；
- `quality_rules`：输出长度、数量、语言、结构和安全规则。

第一版支持的核心变量为：

- `topic`；
- `content`；
- `category`；
- `scene_count`；
- `scene_duration`；
- `min_length`；
- `max_length`；
- `language`；
- `visual_style`；
- `narrations`；
- `safety_rules`。

模板保存前必须验证未知变量、缺失必需变量和空正文，避免运行时才失败。

## 存储与版本策略

软件默认模板以只读数据文件随版本发布，保证任何安装都能离线使用。用户修改保存在工作区数据目录的覆盖文件中，不直接改写软件默认文件。

读取顺序为：

1. 读取软件默认模板；
2. 应用用户启停、正文和推荐项覆盖；
3. 校验合并结果；
4. 如果用户覆盖损坏，则忽略该覆盖并使用默认模板，同时在提示词中心显示警告。

恢复默认值只删除指定模板的用户覆盖，不影响其他模板。外部 GitHub 内容不在软件启动或视频生成时自动下载。

## 生成数据流

1. 视频工坊根据内容来源确定模板用途。
2. 根据栏目和用户选择解析出有效模板。
3. 根据镜头时长计算每段文案长度范围。
4. 将主题、分镜数、栏目规则和安全规则注入模板。
5. 调用当前已配置的 LLM。
6. 校验输出数量、每段长度、语言和必要结构。
7. 第一次不合格时使用纠错提示自动重写一次。
8. 第二次仍不合格则向用户显示明确错误，不把不合格草稿当成成功结果。

知识科普、历史人文和健康生活的事实检索不纳入第一版。本地提示词可以要求谨慎表达和避免编造来源，但不能替代联网事实核验。未来可作为独立功能增加。

## 安全与来源

- 健康生活继续执行不得替代诊疗、不得夸大疗效和必要时建议就医的规则；
- 知识类画面继续执行现有本地模型的禁人物规则；
- 外部提示词只能经过人工筛选和改写后进入默认模板；
- 每个外部启发来源记录项目名称、链接和许可证；
- 不导入没有明确授权的提示词文本；
- 不在运行时执行或信任模板中包含的工具调用、网页指令或系统指令。

## 错误处理

- 模板找不到：回退到同用途的 Morpheus 默认模板；
- 模板变量错误：阻止保存并指出具体变量；
- 用户覆盖损坏：回退默认值并显示非阻塞警告；
- 模型输出过短：自动重写一次；
- 模型输出数量错误：自动重写一次；
- 重写仍失败：保留用户输入并显示可理解的失败原因；
- 本地模板读取失败：不影响资产、项目和设置页面启动。

## 测试要求

自动化测试至少覆盖：

- 八个栏目均能解析推荐模板；
- 模板变量校验；
- 用户覆盖与恢复默认值；
- 禁用模板不会出现在视频工坊；
- 推荐模板选择和回退；
- 主题、分镜数、镜头时长及栏目规则正确注入；
- 过短、数量不符和错误语言触发一次重写；
- 健康安全规则与知识类禁人物规则没有丢失；
- 左侧工具抽屉包含提示词中心；
- 主工作台不增加新的常驻模块。

浏览器验收包括：打开提示词中心、编辑并恢复一个模板、返回视频工坊选择模板、生成草稿并确认草稿长度与分镜数符合设置。

## 第一版不包含

- 运行时连接 GitHub；
- 自动同步外部提示词；
- Langfuse 或其他云端提示词平台；
- 在线知识搜索与事实 RAG；
- 社区模板市场、评分或账号分享；
- 自动改写所有外部提示词；
- 将提示词中心放到主工作台。

这些能力只有在本地模板库稳定并积累真实使用反馈后再评估。
