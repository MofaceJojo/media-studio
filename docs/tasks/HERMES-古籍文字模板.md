## 背景（你需要知道的前提）

本项目用 AI 生成中医药科普短视频。**AI 画不出正确的汉字**——生成的"古籍书页"上全是鬼画符。
所以古籍原文这类画面**不能交给 AI 画**，必须用 HTML 模板把**真实文字**排版渲染成图。

项目已有成熟机制：`templates/<尺寸>/<类型>_<名字>.html`，由 `frame_html.py` 用 Playwright 渲染成 PNG 帧。

## 目标

## 硬性要求

- **文件名前缀必须是 `static_`**：项目按前缀判断模板类型，`static_` 表示不需要 AI 配图（见 `morpheus_video_studio/utils/template_util.py` 的 `get_template_type`）。这是本任务的关键——写错前缀会触发 AI 生图，前功尽弃。
- **占位符只能用这两个**（已核实 `frame_html.py:410` 的替换逻辑，不要自创、不要臆测其它变量名）：
  - `{{title}}` —— 药材名/篇名，作为标题
  - `{{text}}` —— 古籍正文，竖排显示的主体
  （`{{image}}` 仅图片类模板使用，本模板**不要**用）
- 纯 HTML + 内联 CSS，**不引入任何外部字体/JS/图片链接**（离线渲染，外链会导致渲染失败或卡住）。
- 中文字体只用 macOS 系统自带：`PingFang SC`、`Songti SC`、`STSong`，用 font-family 回退链。

## 视觉规格

- 背景：米黄宣纸色（约 `#F3E9D2`），可用 CSS 渐变/噪点模拟纸纹，不要用外部图片

- 长文本要能自动换列且不溢出画面

## 🔴 第二轮验收:再次打回(Claude Code 实测渲染)

**上一轮的三个缺陷已全部修好** ✅ 标题完整、无溢出、构图居中——这部分做得好。

**但引入了一个更严重的新缺陷:阅读顺序错乱,内容变成乱码。**

渲染出的图里,文字是两两横向并排的。按中文竖排的正确读法(**最右一列从上往下读完,再往左移一列**),
读到的是:「当 甘温 主咳 温疟 妇人 子， 疡。 农本」——**完全不成句**。

### 根因(我已定位,不用你再排查)

`static_classic_text.html` 的正文样式里有:

```css
column-count: 8;
```

**CSS 多栏(column-count)与竖排(writing-mode: vertical-rl)不能叠加使用。**
多栏布局会把文本按栏切块重排,竖排本身已经天然产生"列",两者叠加导致字符顺序被打乱。

### 返工要求(只改这一处相关的样式,别动已经修好的边距和居中)

1. **删掉 `column-count`(以及相关的 column-gap 等多栏属性)**。竖排容器只要设定**高度**,文字超出高度时浏览器会自动向左换列——这才是竖排换列的正确方式。
2. 正文容器需要:`writing-mode: vertical-rl` + 固定/最大高度(如 `max-height: 1400px`) + 允许横向延展,让它自然分列。
3. **保留上一轮修好的**:安全边距、水平居中、标题独立成列、长文本不溢出。

### 验收方式(和上轮一样,必须看图)

渲染后打开 PNG,**逐字读一遍最右列**,确认能读出「当归，气味甘温无毒，主咳逆上气……」这样的正常句子。
读不通就是没修好。竖屏横屏都要检查。
